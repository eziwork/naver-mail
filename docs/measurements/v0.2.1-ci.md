각 플랫폼에서 타입 검사, TypeScript 테스트 40개, 설치 도우미 테스트 12개, 실제 배포 압축을 사용하는 도우미 테스트 1개, 12개 MCP 도구 확인, 설정 수명·재접속, Chromium 화면·오류·취소·만료·확대, 반복 유휴·재실행, 배포물의 키링 모듈 로드가 통과했습니다. Mac에서는 부모 프로세스 그룹 종료 후 설정 서버 생존도 확인했습니다. 테스트는 합성 계정과 격리된 폴더를 사용하며 실제 메일을 보내지 않았습니다.

남은 실제 사용자 검증은 팀원 Mac에서 저장소 주소부터 설치·Codex 완전 종료 중 설정 완료·키체인 저장·앱 재접속 후 조회, Safari/Chrome의 실제 키보드 조작·200% 확대와 키체인 접근 거절입니다. CI 통과로 이 항목을 완료 처리하지 않습니다. 개발자 코드서명과 macOS 공증은 미완료입니다.
