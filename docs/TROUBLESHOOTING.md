# 연결 오류와 자주 겪는 문제

[설치 안내](USER_GUIDE.md) · [README](../README.md)

오류 메시지의 종류를 먼저 확인하고 아래 조치를 진행하세요. 비밀번호를 대화에 보내서 해결할 필요는 없습니다.

| 증상 | 확인할 내용과 해결 방법 |
| --- | --- |
| 플러그인이 목록에 없음 | 운영체제용 패키지를 압축 해제한 뒤 로컬 목록에 등록했는지 확인합니다. 앱을 완전히 종료·재시작하고 개인/로컬 목록을 확인합니다. |
| 실행 파일 또는 런타임을 찾지 못함 | GitHub Source code ZIP을 받은 경우 Releases의 OS별 패키지로 바꿉니다. 폴더 일부만 복사하지 말고 전체를 다시 압축 해제합니다. |
| 설치 후 도구가 보이지 않음 | 새 작업을 시작합니다. 이전 작업은 이전 설치 상태를 유지할 수 있습니다. 조직에서 로컬 MCP 사용을 제한하는지도 확인합니다. |
| 연결 브라우저가 열리지 않음 | 대화에 표시된 `127.0.0.1` 연결 링크를 직접 엽니다. 같은 컴퓨터에서 열어야 하며 다른 사람에게 공유하지 않습니다. |
| 연결 화면이 만료됨 / 페이지에 접속할 수 없음 | 30분이 지났거나 앱이 종료된 경우입니다. “네이버 메일 연결 화면을 다시 열어 줘”라고 요청합니다. |
| 비밀번호·인증 오류 | `@naver.com` 주소, 네이버 2단계 인증, IMAP/SMTP 허용을 확인합니다. 일반 로그인 비밀번호 대신 새 앱 비밀번호를 로컬 입력 화면에 입력합니다. |
| 네트워크 오류·시간 초과 | 인터넷과 네이버 메일 웹 접속 상태를 확인합니다. 회사 네트워크에서는 IMAP 993·SMTP 587 연결 허용 여부를 관리자에게 확인합니다. 연결 검사만 다시 진행해도 메일은 발송되지 않습니다. |
| Windows 보안 저장소 오류 | 정상적인 Windows 사용자 로그인 세션에서 실행했는지 확인합니다. 계정 정책이나 자격 증명 관리자 접근 제한은 관리자에게 확인합니다. |
| Mac 키체인 접근 거부·잠금 | 로그인 키체인의 잠금과 접근 요청을 확인합니다. 키체인을 초기화하거나 기존 기록을 일괄 삭제하지 않습니다. |
| Windows 또는 Mac에서 실행을 차단함 | 0.2.0은 개발자 서명·Mac 공증이 완료되지 않았습니다. 오류 문구와 OS 버전을 제보하고 검증·서명된 배포물을 사용합니다. 문서에서는 OS 보호 기능을 일괄 해제하도록 안내하지 않습니다. |
| Node가 계속 보임 | 연결 화면, 진행 중인 작업, 10분 내 발송 계획이 있는지 확인합니다. 이 상태가 끝난 뒤 30초 유휴 시간을 기다립니다. 앱의 다른 기능이 실행한 Node와 구분해야 합니다. |
| 계정을 바꿨더니 발송 준비가 사라짐 | 의도된 동작입니다. 보내는 계정이 다른 미리보기를 재사용하지 않도록 새 계획이 필요합니다. |
| 발송 준비가 만료됨 | 10분이 지났거나 앱/프로세스가 재시작되었습니다. 전체 미리보기를 새로 만들고 확인합니다. |
| 발송 결과를 확인할 수 없음 | 즉시 다시 보내지 않습니다. 네이버 보낸메일함과 수신 여부를 확인하고, 필요할 때만 새 미리보기와 확인을 거칩니다. |
| 첨부파일이 차단됨 | 실행 파일·스크립트·매크로 문서 등 위험 유형일 수 있습니다. 확장자를 바꿔 우회하지 말고 발신자에게 일반 문서 형식으로 다시 요청합니다. |
| 첨부파일 저장 실패 | 다운로드 폴더 권한·용량·보안 표시 적용 가능 여부를 확인합니다. 실패한 파일을 성공한 다운로드로 사용하지 않습니다. |
| 메일을 읽었는데 네이버에서는 안 읽음 | 본문 조회는 읽음 표시를 유지합니다. 변경하려면 “이 메일을 읽음으로 표시해 줘”라고 요청합니다. |

## 계정을 다시 연결하는 순서

“네이버 메일 계정을 다시 연결해 줘”라고 요청하고 새 로컬 화면에서 정보를 입력합니다. 네이버에서 앱 비밀번호를 새로 만들었다면 이전 비밀번호로는 연결되지 않을 수 있습니다. 연결 완료 후 “네이버 메일 연결을 실제로 확인해 줘”로 확인합니다.

다른 PC로 이동했다면 새 PC의 OS 보안 저장소에 따로 연결해야 합니다. 기존 PC의 연결 해제와 네이버 앱 비밀번호 폐기는 서로 다른 조치입니다.

## 업데이트 후 문제가 생겼을 때

앱을 완전히 종료한 뒤 보관한 이전 패키지로 다시 설치하고 새 작업에서 연결 상태를 확인합니다. 운영체제 보안 저장소를 삭제하는 작업은 일반적인 버전 복구에 필요하지 않습니다. 재시작하면 발송 초안은 복원되지 않습니다. 발송 중 발생한 오류는 먼저 수신 여부를 확인하세요.

## 안전하게 문제 제보하기

[GitHub Issues](https://github.com/eziwork/naver-mail/issues)에 다음 내용을 남겨 주세요.

```text
플러그인 버전: 0.2.0
운영체제 / CPU: Windows x64 또는 macOS Intel/Apple Silicon
사용 앱과 버전:
한 작업: 예) 처음 연결 화면에서 연결 검사
기대한 결과:
실제 결과와 오류 문구:
같은 문제가 다시 발생하는 순서:
```

스크린샷에서는 실제 메일 주소·메일 내용·비밀번호·첨부파일 경로·연결 주소의 토큰을 가립니다. 전체 진단 폴더나 키링 내용을 올리지 않습니다. 비밀번호가 공개된 경우에는 네이버에서 해당 앱 비밀번호를 폐기하고 새로 연결합니다.
