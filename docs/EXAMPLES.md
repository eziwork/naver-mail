# 이렇게 부탁해 보세요

[README](../README.md) · [연결 가이드](USER_GUIDE.md) · [문제 해결](TROUBLESHOOTING.md)

계정을 연결한 다음 아래 문장을 대화창에 붙여 넣어 보세요. 검색은 목록부터 시작하고, 필요한 메일을 골라 본문을 확인하면 더 명확한 결과를 얻을 수 있습니다. 예시의 날짜·이름·파일은 자신의 상황에 맞게 바꿔 주세요.

## 업무 시작: 확인할 메일부터

```text
받은메일함의 최근 메일 10개를 보여 줘.
날짜, 보낸 사람, 제목, 읽음 여부를 표로 정리해 줘.
```

목록을 확인한 뒤 이어서 요청하세요.

```text
이 중 두 번째와 세 번째 메일 본문을 읽고
요청 사항, 기한, 내가 할 일을 정리해 줘.
메일에 없는 기한은 '명시 없음'으로 표시해 줘.
```

본문을 조회해도 네이버에서 읽음으로 바뀌지 않습니다. 같은 메일함의 본문은 한 번에 최대 10개까지 조회할 수 있습니다.

## 자료 찾기: 검색 범위를 좁히기

```text
지난달 받은 메일 중 제목에 '계약'이 들어가는 메일을 찾아 줘.
먼저 제목과 보낸 사람만 보여 줘.
```

찾던 메일이 보이면 다음처럼 이어갈 수 있습니다.

```text
첫 번째 메일의 내용을 요약하고 첨부파일 목록을 보여 줘.
```

받은메일함에 없다면 다른 메일함을 지정하거나 날짜·발신자·검색어를 바꿔 보세요. 설치 전 메일도 네이버 서버에 보관되어 있고 IMAP 조회 범위에 포함되면 검색할 수 있습니다.

## 첨부파일: 필요한 파일만 저장하기

```text
방금 확인한 메일의 첨부파일 목록에서
'계약서.pdf'를 저장하고 저장된 위치를 알려 줘.
```

첨부파일은 다운로드 폴더 아래 `Naver Mail Attachments`에 저장됩니다. 메일에 실제로 있는 파일명을 지정하세요. 저장한 외부 파일은 열기 전에 출처를 확인하세요.

## 답장 준비: 작성과 발송을 나누기

```text
이 메일에 '제안해 주신 일정을 확인했고 내부 검토 후 답변드리겠습니다'라는
내용의 정중한 답장을 작성해 줘.
수신자, 참조, 제목, 본문, 첨부 여부를 보내기 전에 전부 보여 줘.
```

미리보기를 검토하고 필요한 부분을 수정하세요. 내용이 맞으면 **새 메시지**에서 다음과 같이 요청합니다.

```text
방금 확인한 수신자와 내용 그대로 보내 줘.
```

발송 준비 내용은 최대 10분 동안 유효합니다. 그 사이에 만료되면 새 미리보기를 다시 확인합니다. 발송 결과가 불명확한 경우에는 재발송을 요청하기 전에 보낸메일함이나 실제 수신 여부를 확인하세요.

## 읽음 표시: 내가 원할 때 변경하기

```text
방금 확인한 메일을 읽음으로 표시해 줘.
```

다시 확인해야 할 메일은 “이 메일을 안 읽음으로 표시해 줘”라고 요청할 수 있습니다. 삭제·이동·예약 발송·상시 감시는 현재 제공하지 않습니다.

## 계정 관리도 대화로

| 하고 싶은 일 | 요청 문장 |
| --- | --- |
| 실제 서버 연결 확인 | “네이버 메일 연결 상태를 실제로 확인해 줘.” |
| 다른 계정 연결 | “네이버 메일 계정을 다시 연결해 줘.” |
| 인증정보 삭제 | “네이버 메일 연결 해제해 줘.” |

선택한 메일 정보는 요청한 작업을 위해 AI 서비스에서 처리됩니다. 필요한 메일만 골라 요청하고, 회사 메일은 조직의 AI 사용 정책을 확인하세요.
